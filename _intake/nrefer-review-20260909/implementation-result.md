# nRefer: ผลแก้ไขและตรวจงาน

อัปเดต 10 กันยายน 2026 หลังตรวจหน้า nRefer 5.0.8 ร่วมกับผู้ใช้

## สิ่งที่เปลี่ยน

- ตัวกรอกใช้ Diagnosis เพื่อให้เว็บคำนวณกลุ่มโรค ตรวจ readback แทนสั่งกรอกช่อง disabled
- วันที่พิมพ์ผ่าน keyboard และยืนยันวันที่ selected ในปฏิทิน รองรับวันเกิดเก่ากว่าช่วง dropdown ปี
- GCS E/V/M ใช้ keyboard เพื่อให้ยอดรวมเปลี่ยนตามพฤติกรรมที่เห็นจริง; ไม่กรอกช่องรวม readonly และไม่เดาคะแนนย่อยจากคะแนนรวม
- จัด radio ก่อนวันเวลา, เลือก mRS/ward ให้ตรงรายการจริง และเตือนช่องที่กรอกหรือยืนยันไม่ได้
- รอคำขอ HIS ที่เริ่มระหว่างกรอก HN/AN ก่อนเติมข้อมูลต้นทาง และตรวจค่าหลังกรอก ลดการถูกข้อมูลตอบกลับทับ
- ไม่สร้างเลขประชาชนจาก HN ไม่เติมเที่ยงคืนเมื่อไม่ทราบเวลา ไม่ใช้ CT/MRI รวมสรุปว่าได้ CT และไม่สมมติผลจำหน่าย
- เพิ่มฟิลด์เสริมที่ขาด รวม CT/ผ่าตัด/Stroke Unit, E/V/M, ผู้นำส่ง, ผลจำหน่าย และ ward; TIA/CVT ต้องเลือก mapping ที่ผู้รับผิดชอบยืนยันเอง
- ผู้ใช้กดบันทึกเองเท่านั้น ไม่มี auto-confirm หรือ API write โดยตัวกรอก
- ฟังผลบันทึกให้ตรง HN+AN+หน่วยงาน ไม่เลือก ref สูงสุดตาม HN; ถ้าบันทึกอาจเกิดแต่ยืนยันไม่ได้ให้สถานะรอตรวจ ป้องกันส่งซ้ำอัตโนมัติ
- กันการเปิดส่งซ้ำภายในฐานข้อมูลท้องถิ่นด้วย transaction และเพิ่มหน้าตรวจคืนสถานะหลังผู้ใช้ตรวจทะเบียนแล้ว
- ปุ่ม “ตรวจฟอร์ม — บล็อกบันทึก” ส่ง --no-save ให้ worker; guard บล็อกคำขอเขียน/endpoint API ที่ไม่อยู่รายการอ่านที่อนุญาต

## การใช้งานและงานยืนยันที่ยังเหลือ

เปิดโปรแกรมใหม่เพื่อโหลดโค้ดและ merge ฟิลด์เสริม จากหน้าเคสเลือก nRefer แล้วใช้ “ตรวจฟอร์ม — บล็อกบันทึก” สำหรับตรวจ end-to-end ครั้งแรก

- อัปเดตรอบ live: Python worker + Edge + ThaID + กรอกข้อมูลสมมติใน --no-save ผ่านถึง final readback โดยไม่มี field failure warnings แล้ว ดูรายละเอียด `live-worker-ledger.md`; ไม่ได้ทดสอบบันทึกจริง และ TS027 เดิมยังไม่ทราบสาเหตุ
- การทดสอบ production ขั้นต่อไปยังต้องใช้โหมดไม่บันทึกและข้อมูลสมมติ ไม่ใช้ผู้ป่วยจริงเพียงเพราะ mock ผ่าน
- แก้ guard ที่บล็อกตรวจ session และรายการ Ward โดยตรวจวิธีเรียกจาก public JS ก่อนอนุญาตแต่ละเส้นทาง; ยังบล็อก endpoint อื่นที่ไม่รู้จัก รวม save/delete
- เคยเห็น HN ว่างในรอบแรก แต่รอบถัดไปที่เพิ่ม diagnostics HN ตรงทุกขั้นตอน จึงยังไม่อ้างว่าพบ root cause หรือแก้ HN แล้ว
- ตัวกันซ้ำตรวจฐานข้อมูลท้องถิ่น ไม่รับรองว่าไม่มี admission ที่บันทึกโดยเครื่องอื่นในทะเบียน nRefer
- ข้อมูลเพิ่มเติม/แบบประเมิน IMC และช่องที่ต้นทางไม่มี ยังต้องให้ผู้ใช้ตรวจและเติมตามจริง

คู่มือผู้ใช้และคำสั่งอยู่ใน `C:\SSCC\app\README.md` ไม่เก็บ token, OAuth code, QR หรือข้อมูลผู้ป่วยในรายงานนี้
