## จุดที่ยังทำให้ต้อง "วนไปมา" — เรียงตามผลกระทบ

### 1. หมวดท้ายสุด "ข้อมูลเพิ่มเติมของ รพ." ผูกกับคำถามที่อยู่กลางฟอร์ม (กระทบทุกเคส rtPA)
7 ช่องท้ายฟอร์ม (#161–167) เปิดตาม **B16 rtPA (#80)** และ **A7.4 AF + C18 (#22, #138)**: ลักษณะเคส rtPA, เวลาที่พบอาการ in-hospital, เหตุ DTN ช้า, AF ไม่ได้ anticoagulant
→ พยาบาลตอบ rtPA ตรง B แล้วเดินต่ออีก 80 ช่อง ค่อยเจอคำถามต่อเนื่องเรื่อง rtPA ตอนจบ = ต้องนึกย้อน
**แก้:** ย้ายด้วย `case_form.arrange()` (กลไกเดียวกับที่ทำ nRefer): `x_b16` → cf_rtpa_event/recog_date/recog_hhmm/dtn_delay/dtn_delay_note; `x_c18_note` → cf_af_no_oac/_note; หมวดท้ายจะเหลือ 0 ช่อง ตัดทิ้งได้ (เก็บ key เดิม)

### 2. ไม่มีตัวนำทางหมวดบนจอปกติ
`#secnav` แสดงเฉพาะจอ ≥1420px — โน้ตบุ๊ก/จอ รพ. ส่วนใหญ่ 1366px จึง**ไม่มี**ทางลัดหมวดเลย ฟอร์ม 9 หมวดต้องเลื่อนหาเอง
**แก้:** แถบชื่อหมวดแบบ sticky ใต้ header ทุกขนาดจอ + ตัวเลขช่องที่ยังว่างในหมวด (ใช้ข้อมูลที่ collect() มีอยู่แล้ว) — พยาบาลเห็นว่าหมวดไหนยังไม่ครบโดยไม่ต้องไล่

### 3. งานจริงกรอก 2 รอบ (แรกรับ / จำหน่าย) แต่ช่องรอบจำหน่ายกระจายปนอยู่กับแรกรับ
ช่องที่รู้ตอนจำหน่ายเท่านั้น: B4 วัน-เวลาจำหน่าย (#43), B8/B10/B12/B14 คะแนนจำหน่าย (#67–73), B19, C13 ภาวะแทรกซ้อน, C15–C19 ยาก่อนกลับ, C20 เสียชีวิต, C21, D2 ผ่าตัด, Motor/mRS ก่อนจำหน่าย — ~25 ช่องกระจายใน 5 หมวด
→ รอบจำหน่ายต้องไล่ทั้งฟอร์มหาช่องเหล่านี้ นี่คือ "วนไปมา" ตัวจริงของงานประจำวัน
**แก้ (ไม่แตะ stored keys):** สวิตช์บนหัวฟอร์ม "แสดง: ทั้งหมด / เฉพาะช่องตอนจำหน่าย" — filter การแสดงผลจาก tag `phase: discharge` ใน schema (เพิ่ม attribute ใน sscc_fields.json/arrange) พร้อมนับ "ยังว่าง N ช่อง" ทำให้รอบสองเป็นรายการสั้น 25 ช่องรันเดียวจบ

### 4. วันที่ 19 ช่องยังเป็นปฏิทินของเบราว์เซอร์
บน Windows ภาษาอังกฤษ = mm/dd/yyyy ค.ศ. ต้องคิดกลับหัว พิมพ์ไม่ได้ตรงๆ กดผิดง่าย (ตระกูลเดียวกับ AM/PM ที่แก้ไปแล้ว และเป็นต้นตอธง "วัน/เดือนสลับ" ใน checks.py)
**แก้:** ช่องพิมพ์ วว/ดด/ปปปป แบบเดียวกับเวลา 24 ชม.: รับ `010969`, `1/9/69`, `01/09/2569`, `2026-09-01` → เก็บ ISO เหมือนเดิม; โชว์ปฏิทินเป็นตัวเลือกไม่ใช่ตัวบังคับ

### 5. รันด้วยคีย์บอร์ดล้วนยังไม่ได้
ปุ่มกด (pills) เป็น radio ที่ซ่อน input — กด Tab/ลูกศรทำงาน แต่**ไม่มี focus ring** (มีเฉพาะ Motor ที่ codex ใส่ให้) → มองไม่เห็นว่าอยู่ช่องไหน
**แก้:** CSS 1 บรรทัด `.pill input:focus-visible + span { outline: 3px solid #6296d6; outline-offset: 2px }`

### 6. คำถามซ้ำที่ยังเหลือ (ราคาถูก คลิกละครั้งแต่ทุกเคส)
- `cf_nrefer_carry` (#9) ถาม "ผู้นำส่ง" ทุกเคสทั้งที่ A6.1 EMS ตอบไปแล้ว → โชว์เฉพาะตัวเลือกที่สอดคล้อง (A6.1 ใช่ → EMS รพ./ท้องถิ่น; ไม่ใช่ → มาเอง/ญาติ) และ default ตัวแรก
- `cf_nrefer_ctscan` (#102) ถาม "ได้ทำ CT ไหม" ซ้ำ C5 ทุกเคส → เปลี่ยนเป็นคำถามเดียว "การตรวจ C5 ข้างบนเป็น CT ใช่ไหม" (ใช่/ไม่ใช่ เป็น MRI) และ default ใช่ เมื่อ C5 = ได้รับการตรวจ
- `cf_nrefer_visit_result` (#146) ทุกเคสที่ไม่ตาย/ไม่ส่งต่อต้องกด "ทุเลา" เอง → preselect ทุเลาเมื่อมีวันจำหน่าย (แก้ได้) พร้อมบอกว่าเป็นค่าเริ่มต้น
- `cf_nrefer_ward` (#34) โผล่ตั้งแต่ยังไม่เลือก B1.1 → ซ่อนจนกว่า B1.1 มีค่าและจับคู่ไม่ได้จริง

## สรุปคำตอบ
- **รอบแรกรับ**: กรอกบนลงล่างรันเดียวจบได้จริง (~90–120 ช่อง ส่วนใหญ่คลิกเดียว ไม่มีช่องโผล่ย้อนหลัง) ยกเว้นข้อ 1 ที่ทิ้งคำถาม rtPA/AF ไว้ท้ายฟอร์ม
- **รอบจำหน่าย**: ยังวน เพราะช่องจำหน่าย 25 ช่องกระจาย 5 หมวดและไม่มีนำทาง (ข้อ 2–3) — นี่คือของที่ควรทำถัดจาก P0
- ลำดับแนะนำให้ codex: 1 → 5 → 6 (งานเล็ก ทำวันเดียว) → 2 → 4 → 3 (โหมดจำหน่าย ใหญ่สุดแต่คุ้มสุด)
