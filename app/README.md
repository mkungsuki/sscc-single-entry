# SSCC Stroke — กรอกครั้งเดียว

โปรแกรมสำหรับ stroke unit: พยาบาลกรอกข้อมูลผู้ป่วย **ครั้งเดียว** แล้วโปรแกรม
1. ไปกรอกเว็บ SSCC (neuronetworks.org/stroke) ให้อัตโนมัติ — พยาบาลตรวจทานก่อนกดบันทึกจริงเสมอ
2. เก็บลงไฟล์ Excel ของ รพ. อัตโนมัติ ไว้ทำวิจัย/KPI — ไม่ต้องกรอกซ้ำอีกรอบ

ข้อมูลทั้งหมดอยู่ในเครื่องนี้เครื่องเดียว ไม่ขึ้น server ไม่เก็บรหัสผ่าน SSCC

## วิธีใช้ประจำวัน (พยาบาล)

1. **ดับเบิลคลิก `start.bat`** → หน้าเว็บโปรแกรมเปิดขึ้นมา (ถ้าไม่เปิด เข้า http://127.0.0.1:8547 เอง)
2. กด **"＋ เคสใหม่"** → กรอกข้อมูลตามชาร์ต เรียงจากบนลงล่าง (ข้อที่ไม่เกี่ยวโปรแกรมซ่อนให้เอง) → กด **"💾 บันทึกร่าง"** ได้ตลอด กรอกไม่จบวันนี้พรุ่งนี้มากรอกต่อได้
3. พร้อมส่งแล้วกด **"🚀 ส่งเข้า SSCC"** → โปรแกรมเปิด Edge ขึ้นมา → **login SSCC ด้วยบัญชีตัวเอง** → โปรแกรมกรอกให้ทุกแท็บเอง → เสร็จแล้ว**เปิดไล่ดูแต่ละแท็บเพื่อตรวจ** → กด **[บันทึก]** บนหน้าเว็บ 1 ครั้ง — จบ สถานะเคสในโปรแกรมจะเปลี่ยนเป็น "ส่ง SSCC แล้ว" เอง

หน้ารวมมีแท็บ **"📝 ร่าง — ยังไม่ส่ง"** ไว้เช็คก่อนกลับบ้านว่ามีเคสค้างส่งไหม

### กรอกให้เร็ว (ไม่ต้องวนไปมา)
- **วันที่พิมพ์ได้เลย** แบบ วว/ดด/ปปปป พ.ศ. — พิมพ์ `010969`, `1/9/69` หรือ `01/09/2569` โปรแกรมจัดให้เป็น 01/09/2569 (ปีเก่าอย่างวันเกิดใส่ 4 หลัก เช่น 04/03/2502) · **เวลา** พิมพ์ `2100` หรือ `21.00` = 21:00 ไม่มี AM/PM
- **แถบหมวดติดหัวจอ** กดข้ามหมวดได้ทุกขนาดจอ และบอกว่าแต่ละหมวดยังว่างกี่ช่อง
- **ปุ่ม "เฉพาะตอนจำหน่าย"** บนแถบหมวด: รอบที่มากรอกตอนจำหน่าย กดแล้วจะเห็นเฉพาะช่องที่รู้ค่าตอนจำหน่าย (วันจำหน่าย คะแนนตอนจำหน่าย ภาวะแทรกซ้อน ยาก่อนกลับ ฯลฯ ~30 ช่อง) ค่าที่กรอกไว้ก่อนไม่หาย กด "ทั้งหมด" เพื่อกลับ
- ช่องที่โปรแกรมรู้คำตอบจากช่องอื่นจะ**ตั้งให้เอง**และบอกที่มาไว้ใต้ช่อง (ผู้นำส่งจาก A6.1, CT จาก C5, ผลจำหน่าย "ทุเลา" เมื่อมีวันจำหน่ายและไม่เสียชีวิต/ส่งต่อ, จังหวัดขอนแก่น) เปลี่ยนได้ทุกช่อง
- คำถามต่อเนื่องเรื่อง rtPA (ลักษณะเคส in-hospital, เหตุ DTN ช้า) อยู่ติดข้อ B16 และเรื่อง AF ไม่ได้ anticoagulant อยู่ติด C18 — ไม่ต้องไปหาท้ายฟอร์ม

### ใช้งานต่อเนื่องโดยไม่ปิดเบราว์เซอร์ทุกเคส

เมื่อส่งจากหน้าโปรแกรม SSCC/nRefer จะใช้เบราว์เซอร์ที่เปิดค้างไว้ และเก็บแท็บเดิมแยกแต่ละระบบ จบเคสแล้วส่งเคสใหม่ภายหลังได้โดยไม่เปิดเบราว์เซอร์ใหม่ หาก session ของเว็บยังใช้ได้ ไม่ต้องล็อกอินซ้ำ หน้าโปรแกรมจะแสดง “พร้อมรับเคสถัดไป”

ระหว่างกรอกหรือตรวจฟอร์มจะไม่รับงานซ้อน ถ้าต้องการเลิกตรวจหรือออกจากงานที่ผิดพลาด กด **“จบรอบนี้ — คงเบราว์เซอร์ไว้”** ในหน้าโปรแกรมและยืนยัน ข้อมูลบนฟอร์มที่ยังไม่บันทึกจะถูกทิ้งและเคสที่เหลือในคิวหยุด แต่ร่างในโปรแกรมยังอยู่ หากมีการบันทึกที่ยืนยันผลไม่ได้ ต้องตรวจทะเบียนก่อนส่งซ้ำ

เปิดโปรแกรมและแท็บทำงานค้างไว้ระหว่างใช้งาน ปิดหน้าต่าง Edge เมื่อเลิกใช้ได้ตามปกติ การปิดโปรแกรม/แท็บ หรือ session หมดอายุที่ฝั่งเว็บ อาจต้องล็อกอินใหม่ โหมดนี้ไม่ย้าย token และไม่อ่าน/เขียนไฟล์ `sscc_session.json` เพื่อคืน session; ใช้ session ที่อยู่ในเบราว์เซอร์จริง

คำสั่ง CLI เดิม (`fill_sscc.py`, `fill_nrefer.py`) และตัวทดสอบโปรไฟล์ชั่วคราวยังเป็นงานครั้งเดียว เส้นทางใช้งานต่อเนื่องคือปุ่มส่งจากหน้าโปรแกรม

### ส่งหลายเคสรวดเดียว (คิว)

กรอกเก็บเป็นร่างไว้ทั้งวัน แล้วค่อยส่งทีเดียวก็ได้:

1. หน้ารวม → แท็บ **"📝 ร่าง"** → ติ๊กเลือกเคสที่จะส่ง (ติ๊กหัวตารางเพื่อเลือกทั้งหน้า)
2. กด **"🚀 ส่งเคสที่เลือกเข้า SSCC"** → Edge เปิดขึ้นมา login ครั้งเดียว
3. โปรแกรมกรอกเคสแรกให้ → **ตรวจแล้วกด [บันทึก] บนเว็บ** → โปรแกรมขึ้นเคสถัดไปให้เองจนหมดคิว

ทุกเคสยังต้องตรวจทานก่อนบันทึกเสมอ (ไม่มีการบันทึกอัตโนมัติ) — คิวแค่ตัดขั้นตอนกลับมากดส่งทีละเคสในโปรแกรม
เคสไหนติดปัญหาจะหยุดคิวและคงฟอร์มไว้ให้ตรวจ ไม่เปิดเคสถัดไปทับ ระหว่างคิววิ่ง หน้ารวมจะมีแถบบอกว่าถึงเคสไหนแล้ว

ไฟล์ Excel รวมทุกเคสชื่อ `SSCC_master.xlsx` (มี 2 ชีต: **"ข้อมูล (อ่านได้)"** ภาษาไทยเต็ม เปิดมาเจอชีตนี้ก่อน / **"รหัสดิบ SSCC"** สำหรับวิเคราะห์หรือเทียบกับเว็บ สป.)
ค่าเริ่มต้นอยู่ที่ `output\` — เปลี่ยนที่เก็บได้จากหน้ารวม (แถวล่างสุด กด **"เปลี่ยนที่เก็บ..."** เลือกโฟลเดอร์ได้เลย)
ปุ่ม **"📊 เปิดไฟล์ Excel"** อยู่ด้านบนข้าง "สร้าง Excel ใหม่" — กดแล้วเปิดไฟล์ดูทันที (ดูเสร็จปิดไฟล์ด้วย ไม่งั้นโปรแกรมเขียนทับไม่ได้)
หรือกด **"📂 เปิดโฟลเดอร์"** (แถวล่างสุด) เพื่อดูทั้งโฟลเดอร์ สำเนากันพังรายวันอยู่ในโฟลเดอร์ย่อย `backups\`
⚠️ อย่าตั้งที่เก็บเป็นโฟลเดอร์ OneDrive/ไดรฟ์แชร์ — ไฟล์มีข้อมูลผู้ป่วย (PDPA)

ไฟล์ Excel อัปเดตเองเบื้องหลังหลังบันทึก/ส่งเคส (ไฟล์ใหญ่ ใช้เวลาราว 15-20 วินาที ไม่ต้องรอ)
⚠️ ถ้าเปิดไฟล์ master ค้างไว้ใน Excel โปรแกรมจะเขียนทับไม่ได้ — หน้ารวมแถวล่างจะขึ้นเตือน
ปิดไฟล์แล้วกด "สร้าง Excel ใหม่" (ข้อมูลในฐานข้อมูลไม่หายไม่ว่ากรณีไหน)

## ตรวจเวลาขัดกันอัตโนมัติ (คุณภาพข้อมูลก่อนส่ง)

ระหว่างกรอก มุมซ้ายล่างจะมีแถบ ⏱ โชว์นาทีที่คำนวณได้ (เริ่มอาการ→ถึง รพ., ถึง รพ.→CT, door-to-needle)
และเตือนถ้าเวลาขัดกัน เช่น ให้ rtPA ก่อน CT, วันที่ให้ยาห่างจากวันมาถึงพอดี 1 เดือน (พิมพ์เดือนผิด),
CT อยู่ก่อนมาถึง รพ. ทั้งที่ไม่ได้เลือกว่าเป็น CT จาก รพ.ต้นทาง, มี AF แต่จำหน่ายด้วยยาต้านเกล็ดเลือดอย่างเดียว ฯลฯ

- **บันทึกร่างได้เสมอ** ไม่บล็อก — แต่ก่อน **ส่งเข้า SSCC** ถ้ายังมีข้อสงสัย โปรแกรมจะให้เลือก "กลับไปแก้" หรือ
  "รับทราบพร้อมเหตุผล" (เคสจริงที่แปลกมีได้ เช่น in-hospital stroke) เหตุผลเก็บไว้กับเคสและลง Excel ไม่ส่งเข้า SSCC
- หน้ารวม → **"🔎 ข้อสงสัยเวลา"** = ลิสต์ทุกเคสที่ติดธง (รวมเคสนำเข้าเก่า) ใช้ไล่แก้บนเว็บ SSCC ได้
- เกณฑ์ทั้งหมดอยู่ใน `checks.py` — เป็นการเทียบเวลาในเคสเดียวกัน ไม่ใช่เกณฑ์ว่า "ต้องเร็ว"

ฟิลด์ รพ. ที่เตรียมไว้ให้ (เปิดใช้อยู่แล้ว โผล่เฉพาะเมื่อเกี่ยว):
- **ลักษณะเคส rtPA** มาถึงด้วยอาการ / อาการเกิด-progress ใน รพ. + เวลาที่พบอาการ → DTN แบบ in-hospital
  คำนวณแยกให้ โดยยังเก็บ door จริงไว้คู่กัน (ไม่ทับกัน)
- **เหตุที่ door-to-needle >45 นาที** (ติ๊กได้หลายข้อ) — เอาไว้ทำ Pareto รายไตรมาส
- **มี AF แต่ไม่ได้ anticoagulant เพราะ** — แยก "มีข้อห้ามจริง" ออกจาก "หลุด" (SSCC ไม่มีช่องนี้)

## เพิ่มฟิลด์ของ รพ. เอง (ทำในโปรแกรม ไม่ต้องแก้ไฟล์)

หน้ารวม → ปุ่ม **"⚙️ ฟิลด์ รพ."** → กด **"＋ เพิ่มหัวข้อใหม่"** ตั้งชื่อ เลือกรูปแบบการกรอก
(ข้อความ / ตัวเลข / ตัวเลือกปุ่มกด / ติ๊กหลายข้อ / วันที่ / เวลา) แล้วบันทึก — เหมือนสร้างคำถามใน Google Form
(เงื่อนไข "แสดงเฉพาะเมื่อ..." ตั้งได้จากไฟล์ `schema\custom_fields.json` คีย์ `show_if` — หน้า UI แค่โชว์ ไม่ลบทิ้ง)

ฟิลด์ใหม่จะโผล่ท้ายฟอร์มหมวด "ข้อมูลเพิ่มเติมของ รพ." ของทุกเคส และเข้า Excel อัตโนมัติ
(เก็บที่ รพ. อย่างเดียว ไม่ส่งเข้า SSCC) — แก้ไข/สลับลำดับ/ปิดใช้ชั่วคราว/ลบ ได้จากหน้าเดียวกัน
ปิดใช้หรือลบแล้วข้อมูลที่เคยกรอกไว้ไม่หาย (ยังอยู่ในฐานข้อมูลและ Excel)

มีตัวอย่างเตรียมไว้ 2 หัวข้อ (mRS 90 วัน, เบอร์โทรติดตาม) แค่ติ๊กเปิดใช้
(สายเทคนิคจะแก้ตรง `schema\custom_fields.json` เองก็ยังได้เหมือนเดิม)

## อัปเดตโปรแกรม (เครื่องที่ใช้งานอยู่)

ดับเบิลคลิก **`update.bat`** — โปรแกรมจะโหลดเวอร์ชันล่าสุดจาก GitHub มาติดตั้งเอง แล้วเปิดโปรแกรมให้
(ฐานข้อมูล / ไฟล์ Excel / การตั้งค่า / ฟิลด์ รพ. **ไม่ถูกแตะ**) — ต้องต่ออินเทอร์เน็ตตอนอัปเดต
ซอร์สโค้ด: https://github.com/mkungsuki/sscc-single-entry (ไม่มีข้อมูลผู้ป่วยใน repo)

## เคสที่ส่งแล้วแต่ข้อมูลบนเว็บไม่ครบ (ส่งซ้ำ/ซ่อม)

เปิดเคสนั้นในโปรแกรม → ปุ่มจะเป็น **"🔧 ส่งซ้ำ (เติมบนเว็บให้ครบ)"** → กด → โปรแกรมเปิด**เคสเดิม**บนเว็บ
(ไม่สร้างเคสซ้ำ) เติมทุกช่องตามข้อมูลในโปรแกรมทับของเดิม → ตรวจทาน → กด [บันทึก] อีกครั้ง — ทำซ้ำได้ไม่จำกัด

## ส่งเข้า nRefer (ทะเบียน Stroke & IMC ของกระทรวง) ด้วยข้อมูลชุดเดียวกัน

ขอนแก่นให้คีย์เคส stroke เข้า nRefer (DMIS/IMC) แยกอีกระบบ — โปรแกรมส่งให้จากข้อมูลชุดเดิมได้ ไม่ต้องคีย์ซ้ำ

- ในเคส: ปุ่ม **"☁ กรอกฟอร์ม nRefer"** → ดูตารางข้อมูลและหมายเหตุ → เลือกเปิด Edge กรอกตามปกติ หรือ **"ตรวจฟอร์ม — บล็อกบันทึก"** สำหรับตรวจโดยไม่ส่งคำขอเขียนข้อมูล
- หน้ารวม: ติ๊กหลายเคส → **"☁ ส่งเคสที่เลือกเข้า nRefer"** (ส่งได้ทุกสถานะ รวมเคสที่ส่ง SSCC ไปแล้ว)
- โปรแกรมเปิด Edge ไปที่ nRefer — **ถ้ายังไม่ได้ login ให้สแกน QR ด้วยแอป ThaID ในหน้าต่าง Edge นั้น** (สแกนครั้งเดียวใช้ได้ทั้งคิว)
  (login ที่ค้างใน Chrome/Brave ของเครื่องใช้ไม่ได้ — โปรแกรมใช้ Edge โปรไฟล์ของมันเอง แยกจากเบราว์เซอร์ที่เปิดเองมือ)
- จากนั้นโปรแกรมกด "Add new" ในหน้าทะเบียน แล้ว**กรอกฟอร์ม "เพิ่มข้อมูล" ของ nRefer ให้ทุกช่องที่มีข้อมูล** (ชื่อ, Dx, วัน-เวลา, rt-PA, CT,
  Stroke Unit, mRS, BP, GCS, ward) แล้ว**หยุด** — ตรวจ เติม Case IMC / แบบประเมิน แล้วกดปุ่ม **[บันทึก]** ของ nRefer เอง
  หลักเดียวกับ SSCC: โปรแกรมไม่กดบันทึกให้และไม่เรียก API เขียนข้อมูลเอง ไม่มี `--auto-confirm` ในตัวกรอกแล้ว ส่งเป็นคิวก็ทีละเคส
- เลือก Dx แล้วตรวจกลุ่มโรคที่เว็บคำนวณเอง (ช่องกลุ่มโรคถูกล็อก), พิมพ์วันที่ พ.ศ. แล้วตรวจวัน/เดือน/ปีที่ปฏิทินเลือกจริง, เลือก mRS/ward จากรายการและอ่านค่ากลับ
- อายุ (ปี) และ LOS โปรแกรมกรอกให้ (nRefer ไม่คำนวณเองจากวันที่ เว้นแต่ดึงจาก HIS) — ตรวจก่อนบันทึก
- เคสเก่าที่ส่งแล้วอาจไม่โผล่ในหน้าทะเบียนทันที เพราะ nRefer กรองด้วยช่วง "วันที่อยู่รักษา" (ค่าเริ่มต้นราว 6 เดือน) — ขยับช่วงวันที่หรือค้นด้วย HN
- ผลบันทึกต้องมาจากคำขอที่ตรง **HN + AN + หน่วยงาน**; เก็บ ref เฉพาะเมื่อผลตอบกลับระบุรายการที่ตรงกัน ไม่หา `max(ref)` ของ HN หากเว็บไม่คืนเลขที่ยืนยันได้ จะแสดงส่งแล้วโดยไม่มีเลข ref
- เคสที่ส่งแล้วปุ่มเปลี่ยนเป็นเปิดทะเบียนเพื่อตรวจ/แก้เอง ไม่เปิด Add new ซ้ำ และกัน HN/AN ซ้ำข้ามเคสในฐานเครื่องนี้ด้วย ทั้งนี้ไม่ได้รับรองว่าไม่มีเคสเดิมที่กรอกด้วยมือในทะเบียนออนไลน์
- ถ้าปิดหน้า/หมดเวลาหลังมีคำขอบันทึก หรือโปรเซสหยุดกลางทาง จะแสดง **"ต้องตรวจผล"** ให้รีเฟรชหน้าเคส เปิดทะเบียนตรวจ HN/AN และช่วงวันที่ แล้วระบุว่าพบหรือไม่พบรายการก่อนเริ่มใหม่ ไม่ถือว่า timeout แปลว่าไม่มีข้อมูลถูกบันทึก
- ต้องกรอก **HN และ AN** ก่อนส่ง; ไม่มีเลขบัตรประชาชนจะเว้นว่าง ไม่เอา HN แทน; ไม่ทราบเวลาจะเว้นว่าง ไม่ใส่เที่ยงคืนแทน
- ฟิลด์ รพ. เพิ่มเติม: วันเกิด, BP, CT ที่แยกจาก MRI และวันเวลา CT, GCS E/V/M, ประเภทผู้นำส่ง, ผลจำหน่าย, ชื่อ ward, เวลาเข้า Stroke Unit/ผ่าตัด รองรับการเว้นไว้ตรวจเอง
- **GCS รวมเป็น readonly** โปรแกรมพิมพ์ E/V/M ผ่านคีย์บอร์ดเพื่อให้เว็บคำนวณ (ตรวจเว็บจริงพบว่า fill + Tab อย่างเดียวยอดรวมค้างได้) ไม่ฝืนกรอกคะแนนรวมและไม่เดา E/V/M; หากผลรวมบนเว็บไม่ตรง SSCC จะเตือนให้ตรวจ
- TIA/CVT ต้องให้เจ้าของทะเบียนยืนยัน ICD ที่ถูกต้องและเกณฑ์รับเข้าทะเบียนก่อนระบุในฟิลด์ nRefer ไม่เปลี่ยนรหัสเพื่อให้ผ่านระบบโดยไม่มีเหตุผลทางข้อมูล; Stroke mimics และไม่มี Dx ยังไม่ส่ง
- Ward ที่จับคู่ชื่อได้แน่นอนใช้รายการจริง; รหัสที่กำกวมต้องเลือกเอง ส่วน Case IMC/แบบประเมิน BI/พิกัดบ้านให้ตรวจและเติมบน nRefer ตามข้อมูลจริง
- ปิดฟีเจอร์นี้: ตั้ง `"nrefer_enabled": false` ใน `config.json`

รหัสแปลงอยู่ใน `nrefer_map.py`, การกรอก/ตรวจ UI อยู่ใน `nrefer_ui.py`, ตัวดำเนินงานคือ `fill_nrefer.py`, ตัวฟังผลบันทึกคือ `nrefer_save.py`
เทสต์: `python mock\test_nrefer.py` — สร้าง source/DB/store ชั่วคราวแยกก่อนรัน ไม่แตะฐานเคสจริง ห้ามรัน `test_nrefer_cases.py` ตรง (มีด่านกันไว้)

ลอง worker จริงกับข้อมูลสมมติ: `python mock\live_nrefer_inspection.py` — เปิด Edge และฐานข้อมูล/โปรไฟล์ชั่วคราวแยก ให้ผู้ใช้สแกน ThaID แล้วรันตัวกรอกเดิมด้วย `--no-save` เสมอ ตรวจเสร็จให้ปิด Edge (รอสูงสุด 15 นาทีหลังกรอก) ไม่คัดลอกเคสหรือโปรไฟล์ใช้งานจริงเข้าการทดสอบ

โหมดตรวจจาก CLI: `python fill_nrefer.py --cases <id> --no-save` หลัง login จะอนุญาตเฉพาะเส้นทางตรวจ session, อ่าน patient/person และรายการอ้างอิงพร้อมวิธีเรียกที่ยืนยันจากโค้ดสาธารณะของเว็บแล้ว และปิด service workers เพื่อให้การบล็อกครอบคลุม request ของหน้า เว็บอาจโหลดรายการอ้างอิงบางอย่างไม่ได้ในโหมดนี้ ให้รายงานเส้นทางที่ขาดก่อนขยาย allowlist ห้ามยกเลิกตัวบล็อกเพื่อให้เทสต์ผ่าน

**หลักฐานทดสอบ:** ตรวจ widget จริงวันที่ 9–10 กันยายน 2026 และรัน worker Python ผ่าน Edge + ThaID ด้วยข้อมูลสมมติในโหมดบล็อกบันทึกได้ถึง final readback โดยไม่มีคำเตือนกรอกช่องล้มเหลวแล้ว รวม HN, Ward และ GCS รวม 12 หลังแก้ allowlist สำหรับตรวจ session/อ่าน Ward ทดสอบท้องถิ่นผ่าน 27 ข้อ ไม่ได้ทดสอบบันทึกจริง สาเหตุ TS027 และ HN ว่างที่เกิดในรอบก่อนยังไม่ยืนยัน รายละเอียดอยู่ใน `_intake/nrefer-review-20260909/live-worker-ledger.md`

หลังอัปเดตให้เปิดโปรแกรมใหม่เพื่อโหลดโค้ดและเพิ่มฟิลด์ตั้งต้นที่ยังไม่มี เก็บฟิลด์ รพ. ที่ผู้ใช้ปรับไว้ตามระบบ merge เดิม

⚠️ zip แบบ `--with-data` มีข้อมูลผู้ป่วย — ย้ายด้วย USB เท่านั้น ห้ามส่งผ่าน LINE/email/cloud

## ปัญหาที่พบได้ / ข้อควรรู้

- **ฟอร์มกรอกครั้งเดียว**: ช่องเพิ่มเติมอยู่ข้างข้อมูลคลินิกที่เกี่ยวข้องแล้ว GCS รวมกับ E/V/M อยู่กลุ่มเดียวและคำนวณรวมเมื่อกรอกครบ; Ward/วินิจฉัย/ผลจำหน่ายใช้ข้อมูลเดิมที่จับคู่ได้ ส่วนเวลาทำ CT เลือกใช้เวลา C5 ได้เมื่อยืนยันว่าเป็น CT ครั้งเดียวกัน ตัวเลือก ICD แสดงชื่อโรคข้างรหัส

- **เว็บ SSCC ปรับหน้าใหม่แล้วโปรแกรมกรอกไม่ลง**: โครงสร้างฟอร์มอยู่ใน `schema/sscc_fields.json` — สำรวจหน้าเว็บใหม่แล้วรัน `tools/build_schema.py` (หรือให้ Claude Code ช่วยอัปเดต)
- **ช่องยา C18**: บนเว็บจริงเป็นช่องค้นหายา โปรแกรมใส่ชื่อยาให้ตรงๆ — ตอนตรวจทานช่วยดูช่องนี้เป็นพิเศษ ถ้าไม่ขึ้นให้กดปุ่มแว่นขยายค้นหาเอง (ยังไม่ได้ทดสอบกับเว็บจริง)
- **ระหว่างโปรแกรมกรอก ห้ามคลิก/ปิดหน้าต่าง Edge** — บนหน้าเว็บจะมีแถบสีส้มบอกว่า "กำลังกรอกอัตโนมัติ"
  รอจนแถบเปลี่ยนเป็นสีเขียว "ตรวจทานแล้วกดบันทึก" ค่อยจับเมาส์ (ถ้าเผลอคลิกจนหน้าเปลี่ยน
  โปรแกรมจะเปิดหน้าใหม่แล้วกรอกซ้ำให้เองสูงสุด 3 รอบ)
- **ต้อง login ใหม่ทุกครั้งที่ส่งเคส**: ใช้ปุ่มส่งจากหน้าโปรแกรมรุ่นนี้และคงหน้าต่าง Edge/แท็บเดิมไว้ ไม่ใช้ CLI แบบครั้งเดียว หากยังเกิดซ้ำขณะไม่ได้ปิดหน้าต่าง ให้ตรวจการหมดอายุหรือ logout ของเว็บ; การคงเบราว์เซอร์ไม่ยืดอายุ session ที่เซิร์ฟเวอร์กำหนด
- **ส่งเคสค้าง/ปิด Edge ก่อนบันทึก**: เคสยังเป็น "ร่าง" กดส่งใหม่ได้เลย — โปรแกรมจำเลขเคสบนเว็บไว้แล้ว
  จะเปิดกรอกต่อที่เคสเดิม ไม่สร้างเคสซ้ำบนเว็บ
- **Motor power แบบ Stroke**: การ์ดใกล้ GCS มีคะแนนแขนซ้าย/ขวาและขาซ้าย/ขวา 0–5 คัดลอกเป็นค่าเริ่มต้นสำหรับทะเบียน: แขน → C5–T1, ขา → L2–S1 ด้านเดียวกัน เปิด “ดู / แก้รายช่อง” เมื่อมีค่าต่างกัน ค่าที่แก้แยกจะคงอยู่แม้เปลี่ยนคะแนนสรุป ล้างคะแนนสรุปไม่ลบค่าที่แก้แยก; เลือก “ตามคะแนนสรุป” เพื่อเลิก override
- **กรอก Motor ใน nRefer**: บันทึกคะแนนให้ครบ แล้วกด “กรอก Motor power ใน nRefer” เปิดเคสเดิมกับแท็บ 7 ในหน้าต่าง Edge ของโปรแกรม และกด “เติมคะแนนในตารางนี้” โปรแกรมตรวจ HN/AN แล้วกรอกและอ่านกลับ 20 ช่อง ผู้ใช้เลือกชุดประเมิน ตรวจวันเวลา/ผู้ประเมิน แก้รายละเอียดและกดบันทึกเอง ตัวช่วยนี้ไม่สร้างข้อมูลหลักใหม่และไม่เปลี่ยนสถานะการส่งข้อมูลหลัก เก็บกติกาคัดลอก/ค่าที่แก้แยกไว้ในเคส; ไม่ได้คำนวณการจัดระดับ AIS
- **หลังอัปเดตฟอร์ม Motor**: บันทึกงานที่เปิดไว้แล้วปิด/เปิดโปรแกรมใหม่ เพื่อโหลด Python และ template รุ่นใหม่ ทดสอบอัตโนมัติด้วย `python mock/test_nrefer.py` (สำเนาชั่วคราวและข้อมูลจำลอง)
- **PDPA**: ไฟล์ทุกไฟล์อยู่เครื่องนี้เครื่องเดียว ห้ามแชร์โฟลเดอร์ `data/` และ `output/` ขึ้น cloud/แชร์ไดรฟ์โดยไม่จำเป็น
