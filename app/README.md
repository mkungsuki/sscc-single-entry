# SSCC Stroke — กรอกครั้งเดียว

โปรแกรมสำหรับ stroke unit: พยาบาลกรอกข้อมูลผู้ป่วย **ครั้งเดียว** แล้วโปรแกรม
1. ไปกรอกเว็บ SSCC (neuronetworks.org/stroke) ให้อัตโนมัติ — พยาบาลตรวจทานก่อนกดบันทึกจริงเสมอ
2. เก็บลงไฟล์ Excel ของ รพ. อัตโนมัติ ไว้ทำวิจัย/KPI — ไม่ต้องกรอกซ้ำอีกรอบ

ข้อมูลทั้งหมดอยู่ในเครื่องนี้เครื่องเดียว ไม่ขึ้น server ไม่เก็บรหัสผ่าน SSCC

## วิธีใช้ประจำวัน (พยาบาล)

1. **ดับเบิลคลิก `start.bat`** → หน้าเว็บโปรแกรมเปิดขึ้นมา (ถ้าไม่เปิด เข้า http://127.0.0.1:8547 เอง)
2. กด **"＋ เคสใหม่"** → กรอกข้อมูลตามชาร์ต เรียงจากบนลงล่าง (ข้อที่ไม่เกี่ยวโปรแกรมซ่อนให้เอง) → กด **"💾 บันทึกร่าง"** ได้ตลอด กรอกไม่จบวันนี้พรุ่งนี้มากรอกต่อได้
3. พร้อมส่งแล้วกด **"🚀 ส่งเข้า SSCC"** → โปรแกรมเปิด Edge ขึ้นมา → **login SSCC ด้วยบัญชีตัวเอง** → โปรแกรมกรอกให้ทุกแท็บเอง → เสร็จแล้ว**เปิดไล่ดูแต่ละแท็บเพื่อตรวจ** → กด **[บันทึก]** บนหน้าเว็บ 1 ครั้ง — จบ สถานะเคสในโปรแกรมจะเปลี่ยนเป็น "ส่ง SSCC แล้ว" เอง

หน้ารวมมีแท็บ **"📝 ร่าง — ยังไม่ส่ง"** ไว้เช็คก่อนกลับบ้านว่ามีเคสค้างส่งไหม

### ส่งหลายเคสรวดเดียว (คิว)

กรอกเก็บเป็นร่างไว้ทั้งวัน แล้วค่อยส่งทีเดียวก็ได้:

1. หน้ารวม → แท็บ **"📝 ร่าง"** → ติ๊กเลือกเคสที่จะส่ง (ติ๊กหัวตารางเพื่อเลือกทั้งหน้า)
2. กด **"🚀 ส่งเคสที่เลือกเข้า SSCC"** → Edge เปิดขึ้นมา login ครั้งเดียว
3. โปรแกรมกรอกเคสแรกให้ → **ตรวจแล้วกด [บันทึก] บนเว็บ** → โปรแกรมขึ้นเคสถัดไปให้เองจนหมดคิว

ทุกเคสยังต้องตรวจทานก่อนบันทึกเสมอ (ไม่มีการบันทึกอัตโนมัติ) — คิวแค่ตัดขั้นตอนกลับมากดส่งทีละเคสในโปรแกรม
เคสไหนติดปัญหาโปรแกรมจะข้ามให้ (ยังเป็นร่างเหมือนเดิม) แล้วไปต่อเคสถัดไป ระหว่างคิววิ่ง หน้ารวมจะมีแถบบอกว่าถึงเคสไหนแล้ว

ไฟล์ Excel รวมทุกเคสชื่อ `SSCC_master.xlsx` (มี 2 ชีต: รหัสดิบสำหรับวิเคราะห์ / ฉบับอ่านได้)
ค่าเริ่มต้นอยู่ที่ `output\` — เปลี่ยนที่เก็บได้จากหน้ารวม (แถวล่างสุด กด **"เปลี่ยนที่เก็บ..."** เลือกโฟลเดอร์ได้เลย
กด **"📂 เปิดโฟลเดอร์"** เพื่อเปิดดูไฟล์) สำเนากันพังรายวันอยู่ในโฟลเดอร์ย่อย `backups\`
⚠️ อย่าตั้งที่เก็บเป็นโฟลเดอร์ OneDrive/ไดรฟ์แชร์ — ไฟล์มีข้อมูลผู้ป่วย (PDPA)

ไฟล์ Excel อัปเดตเองเบื้องหลังหลังบันทึก/ส่งเคส (ไฟล์ใหญ่ ใช้เวลาราว 15-20 วินาที ไม่ต้องรอ)
⚠️ ถ้าเปิดไฟล์ master ค้างไว้ใน Excel โปรแกรมจะเขียนทับไม่ได้ — หน้ารวมแถวล่างจะขึ้นเตือน
ปิดไฟล์แล้วกด "สร้าง Excel ใหม่" (ข้อมูลในฐานข้อมูลไม่หายไม่ว่ากรณีไหน)

## ตรวจเวลาขัดกันอัตโนมัติ (คุณภาพข้อมูลก่อนส่ง)

ระหว่างกรอก มุมซ้ายล่างจะมีแถบ ⏱ โชว์นาทีที่คำนวณได้ (เริ่มอาการ→ถึง รพ., ถึง รพ.→CT, door-to-needle)
และเตือนถ้าเวลาขัดกัน เช่น ให้ rtPA ก่อน CT, วันที่ให้ยาห่างจากวันมาถึงพอดี 1 เดือน (พิมพ์เดือนผิด),
CT อยู่ก่อนมาถึง รพ. ทั้งที่ไม่ได้เลือกว่าเป็น CT จาก รพ.ต้นทาง, มี AF แต่จำหน่ายด้วยยาต้านเกล็ดเลือดอย่างเดียว ฯลฯ

- **บันทึกร่างได้เสมอ** ไม่บล็อก — แต่ก่อน **ส่งเข้า SSCC** ถ้ายังมีข้อสงสัย โปรแกรมจะให้เลือก "กลับไปแก้" หรือ
  "รับทราบพร้อมเหตุผล" (เคสจริงที่แปลกมีได้ เช่น in-hospital stroke) เหตุผลเก็บไว้กับเคสและลง Excel ไม่ส่งเข้า SSCC
- หน้ารวม → **"🔎 ข้อสงสัยเวลา"** = ลิสต์ทุกเคสที่ติดธง (รวมเคสนำเข้าเก่า) ใช้ไล่แก้บนเว็บ SSCC ได้
- เกณฑ์ทั้งหมดอยู่ใน `checks.py` — เป็นการเทียบเวลาในเคสเดียวกัน ไม่ใช่เกณฑ์ว่า "ต้องเร็ว"

ฟิลด์ รพ. ที่เตรียมไว้ให้ (เปิดใช้อยู่แล้ว โผล่เฉพาะเมื่อเกี่ยว):
- **ลักษณะเคส rtPA** มาถึงด้วยอาการ / อาการเกิด-progress ใน รพ. + เวลาที่พบอาการ → DTN แบบ in-hospital
  คำนวณแยกให้ โดยยังเก็บ door จริงไว้คู่กัน (ไม่ทับกัน)
- **เหตุที่ door-to-needle >45 นาที** (ติ๊กได้หลายข้อ) — เอาไว้ทำ Pareto รายไตรมาส
- **มี AF แต่ไม่ได้ anticoagulant เพราะ** — แยก "มีข้อห้ามจริง" ออกจาก "หลุด" (SSCC ไม่มีช่องนี้)

## เพิ่มฟิลด์ของ รพ. เอง (ทำในโปรแกรม ไม่ต้องแก้ไฟล์)

หน้ารวม → ปุ่ม **"⚙️ ฟิลด์ รพ."** → กด **"＋ เพิ่มหัวข้อใหม่"** ตั้งชื่อ เลือกรูปแบบการกรอก
(ข้อความ / ตัวเลข / ตัวเลือกปุ่มกด / ติ๊กหลายข้อ / วันที่ / เวลา) แล้วบันทึก — เหมือนสร้างคำถามใน Google Form
(เงื่อนไข "แสดงเฉพาะเมื่อ..." ตั้งได้จากไฟล์ `schema\custom_fields.json` คีย์ `show_if` — หน้า UI แค่โชว์ ไม่ลบทิ้ง)

ฟิลด์ใหม่จะโผล่ท้ายฟอร์มหมวด "ข้อมูลเพิ่มเติมของ รพ." ของทุกเคส และเข้า Excel อัตโนมัติ
(เก็บที่ รพ. อย่างเดียว ไม่ส่งเข้า SSCC) — แก้ไข/สลับลำดับ/ปิดใช้ชั่วคราว/ลบ ได้จากหน้าเดียวกัน
ปิดใช้หรือลบแล้วข้อมูลที่เคยกรอกไว้ไม่หาย (ยังอยู่ในฐานข้อมูลและ Excel)

มีตัวอย่างเตรียมไว้ 2 หัวข้อ (mRS 90 วัน, เบอร์โทรติดตาม) แค่ติ๊กเปิดใช้
(สายเทคนิคจะแก้ตรง `schema\custom_fields.json` เองก็ยังได้เหมือนเดิม)

## อัปเดตโปรแกรม (เครื่องที่ใช้งานอยู่)

ดับเบิลคลิก **`update.bat`** — โปรแกรมจะโหลดเวอร์ชันล่าสุดจาก GitHub มาติดตั้งเอง แล้วเปิดโปรแกรมให้
(ฐานข้อมูล / ไฟล์ Excel / การตั้งค่า / ฟิลด์ รพ. **ไม่ถูกแตะ**) — ต้องต่ออินเทอร์เน็ตตอนอัปเดต
ซอร์สโค้ด: https://github.com/mkungsuki/sscc-single-entry (ไม่มีข้อมูลผู้ป่วยใน repo)

## เคสที่ส่งแล้วแต่ข้อมูลบนเว็บไม่ครบ (ส่งซ้ำ/ซ่อม)

เปิดเคสนั้นในโปรแกรม → ปุ่มจะเป็น **"🔧 ส่งซ้ำ (เติมบนเว็บให้ครบ)"** → กด → โปรแกรมเปิด**เคสเดิม**บนเว็บ
(ไม่สร้างเคสซ้ำ) เติมทุกช่องตามข้อมูลในโปรแกรมทับของเดิม → ตรวจทาน → กด [บันทึก] อีกครั้ง — ทำซ้ำได้ไม่จำกัด

## นำเข้าข้อมูลเก่าจาก SSCC

กดปุ่ม export (Excel/CSV) บนหน้า list ของเว็บ SSCC แล้วรัน:

```
python import_export.py C:\path\to\stroke_form.csv
```

รันซ้ำได้ — เคสที่มีอยู่แล้วจะถูกข้าม (นำเข้าไปแล้ว 3,999 เคส เมื่อ 2026-07-13)

## โครงสร้างไฟล์

| ไฟล์ | หน้าที่ |
|---|---|
| `server.py` | หน้าเว็บกรอกข้อมูล (Flask, http://127.0.0.1:8547) |
| `checks.py` | ตรวจเวลาขัดกัน/คุณภาพข้อมูล (แถบ ⏱ ในฟอร์ม, หน้า "ข้อสงสัยเวลา", ด่านก่อนส่ง) |
| `fill_sscc.py` | หุ่นยนต์กรอกเว็บ SSCC (Playwright + Edge) |
| `schema/sscc_fields.json` | โครงสร้างฟอร์ม SSCC ทั้ง 136 ฟิลด์ (แกะจากเว็บจริง 2026-07-13) |
| `schema/custom_fields.json` | ฟิลด์เพิ่มเติมของ รพ. — แก้ไฟล์นี้เพื่อเพิ่มฟิลด์ |
| `data/sscc.db` | ฐานข้อมูลเคสทั้งหมด (SQLite) |
| `excel_export.py` / `import_export.py` | สร้าง Excel master / นำเข้าข้อมูลเก่า |
| `runlock.py` | กันกดส่ง SSCC ซ้อนกัน (Edge โปรไฟล์เดียว เปิดพร้อมกันสองตัวไม่ได้) |
| `mock/` | เว็บ SSCC จำลอง + เทสต์อัตโนมัติ (`python mock\test_e2e.py`, `python mock\test_queue.py`) |
| `tools/build_schema.py` | สร้าง schema ใหม่จากไฟล์สำรวจใน `C:\SSCC\_intake\schema\` |

## ติดตั้งครั้งแรก (เครื่องใหม่) / ย้ายไปเครื่องพยาบาล

วิธีง่ายสุด — สร้าง zip พร้อมคู่มือติดตั้งในตัว:

```
python tools\make_deploy_zip.py              ← โปรแกรมเปล่า (เริ่มเคสใหม่จากศูนย์)
python tools\make_deploy_zip.py --with-data  ← พกฐานข้อมูลเคสทั้งหมดไปด้วย (ย้ายเครื่องหลัก)
```

ได้ไฟล์ `SSCC_deploy_วันที่.zip` ที่ `C:\SSCC` — เครื่องปลายทางแค่**แตก zip แล้วดับเบิลคลิก `setup.bat`**
มันจะติดตั้ง Python + ไลบรารีให้เอง สร้างทางลัด "SSCC Stroke" บนหน้าจอ แล้วเปิดโปรแกรมเลย
(Edge มีใน Windows อยู่แล้ว ไม่ต้องลงเบราว์เซอร์เพิ่ม — ถ้าติดตั้ง Python อัตโนมัติไม่ได้
มันจะเปิด python.org ให้ลงเอง **ติ๊ก Add python.exe to PATH** แล้วรัน setup.bat ซ้ำ)

⚠️ zip แบบ `--with-data` มีข้อมูลผู้ป่วย — ย้ายด้วย USB เท่านั้น ห้ามส่งผ่าน LINE/email/cloud
(สิ่งที่ไม่ติดไปกับ zip: session login (`data\edge_profile`) พยาบาล login ใหม่ด้วยบัญชีตัวเอง,
ที่เก็บ Excel ถูกรีเซ็ตเป็นค่าเริ่มต้น, ไฟล์ mock/เทสต์)

## ปัญหาที่พบได้ / ข้อควรรู้

- **เว็บ SSCC ปรับหน้าใหม่แล้วโปรแกรมกรอกไม่ลง**: โครงสร้างฟอร์มอยู่ใน `schema/sscc_fields.json` — สำรวจหน้าเว็บใหม่แล้วรัน `tools/build_schema.py` (หรือให้ Claude Code ช่วยอัปเดต)
- **ช่องยา C18**: บนเว็บจริงเป็นช่องค้นหายา โปรแกรมใส่ชื่อยาให้ตรงๆ — ตอนตรวจทานช่วยดูช่องนี้เป็นพิเศษ ถ้าไม่ขึ้นให้กดปุ่มแว่นขยายค้นหาเอง (ยังไม่ได้ทดสอบกับเว็บจริง)
- **ระหว่างโปรแกรมกรอก ห้ามคลิก/ปิดหน้าต่าง Edge** — บนหน้าเว็บจะมีแถบสีส้มบอกว่า "กำลังกรอกอัตโนมัติ"
  รอจนแถบเปลี่ยนเป็นสีเขียว "ตรวจทานแล้วกดบันทึก" ค่อยจับเมาส์ (ถ้าเผลอคลิกจนหน้าเปลี่ยน
  โปรแกรมจะเปิดหน้าใหม่แล้วกรอกซ้ำให้เองสูงสุด 3 รอบ)
- **ต้อง login SSCC ใหม่ทุกครั้งที่ส่งเคส**: session ของ SSCC เป็น cookie ชั่วคราวที่หายเมื่อปิด Edge —
  ตั้งแต่เวอร์ชัน 2026-08 โปรแกรมเก็บ session ไว้เองใน `data\sscc_session.json` แล้วใส่คืนตอนเปิดรอบถัดไป
  (login ครั้งเดียวใช้ได้จนกว่า server SSCC จะตัด session เอง — ถ้าเว้นนานเป็นชั่วโมงอาจถูกถาม login อีกครั้ง เป็นเรื่องฝั่ง server)
  ไฟล์นี้คือ "ตั๋ว login" ของบัญชีล่าสุด อยู่ในเครื่องนี้เท่านั้น ไม่ติดไปกับ zip/GitHub — ถ้าจะเปลี่ยนบัญชี ลบไฟล์นี้แล้ว login ใหม่
- **ส่งเคสค้าง/ปิด Edge ก่อนบันทึก**: เคสยังเป็น "ร่าง" กดส่งใหม่ได้เลย — โปรแกรมจำเลขเคสบนเว็บไว้แล้ว
  จะเปิดกรอกต่อที่เคสเดิม ไม่สร้างเคสซ้ำบนเว็บ
- **PDPA**: ไฟล์ทุกไฟล์อยู่เครื่องนี้เครื่องเดียว ห้ามแชร์โฟลเดอร์ `data/` และ `output/` ขึ้น cloud/แชร์ไดรฟ์โดยไม่จำเป็น
